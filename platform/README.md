# Supply Chain Intelligence Platform

Phase 7 evolves the project from a report-oriented Power BI deliverable into an interactive supply-chain intelligence platform.

## Architecture

- Frontend: Next.js + React + TypeScript
- Styling: Tailwind CSS
- Motion: Framer Motion
- 2D analytics: Apache ECharts
- 3D: Three.js / React Three Fiber
- Backend: FastAPI + Python
- Database: MySQL
- BI: Power BI + DAX
- Containers: Docker Compose

## Product areas

1. Control Tower
2. Demand Intelligence
3. Inventory Intelligence
4. Action Center
5. Store Explorer
6. Product Explorer
7. Analytics / Power BI

The platform consumes the validated Phase 5 forecast layer and Phase 6 inventory decision layer. It must not invent operational metrics or business impact.
