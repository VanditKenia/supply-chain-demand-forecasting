# API Documentation

## API identity

The backend is a FastAPI application named **Supply Chain Intelligence API**, version `0.1.0`.

Current implementation source:

- `backend/app/main.py`
- `backend/app/data_service.py`

Only endpoints that currently exist in the code are documented here.

## 1. Health check

### GET `/health`

Purpose: verify that the API process is running.

### Parameters

None.

### Example request

```http
GET /health
```

### Example response

```json
{
  "status": "ok",
  "service": "supply-chain-intelligence-api"
}
```

### Errors

No custom application error is defined by this route.

## 2. API root

### GET `/api`

Purpose: return basic API identity and foundation status.

### Parameters

None.

### Example request

```http
GET /api
```

### Example response

```json
{
  "name": "Supply Chain Intelligence API",
  "version": "0.1.0",
  "status": "foundation"
}
```

## 3. Overview

### GET `/api/overview`

Purpose: return summary metrics derived from the forecast and inventory analytical artifacts.

### Parameters

None.

### Response fields

| Field | Meaning |
|---|---|
| forecast_records | Number of forecast rows |
| decision_units | Number of inventory decision rows |
| stores | Unique stores in forecast data |
| products | Unique products in forecast data |
| forecast_horizon_days | Unique forecast dates |
| total_forecast_demand | Sum of Forecast_Demand |
| high_risk_units | Count of inventory rows with Risk = High |
| recommended_order_units | Sum of Recommended Order Quantity |

### Example response

```json
{
  "forecast_records": 3000,
  "decision_units": 100,
  "stores": 5,
  "products": 20,
  "forecast_horizon_days": 30,
  "total_forecast_demand": 278398.48,
  "high_risk_units": 95,
  "recommended_order_units": 52083
}
```

### Errors

If a required analytical artifact is missing, the route converts the resulting `FileNotFoundError` to HTTP 503 with a detail message.

## 4. Actions

### GET `/api/actions`

Purpose: return inventory decision records used by the action-oriented application layer.

### Query parameter

`risk` — optional string filter. Matching is case-insensitive.

Examples:

```http
GET /api/actions
GET /api/actions?risk=High
GET /api/actions?risk=medium
```

### Response structure

The route returns a JSON array of records with:

- Store ID
- Product ID
- Current Inventory
- Lead Time Demand
- Safety Stock
- Reorder Point
- Inventory Gap
- Recommended Order Quantity
- Risk
- Recommended Action
- Priority

### Example response

```json
[
  {
    "Store ID": "S001",
    "Product ID": "P0001",
    "Current Inventory": 100,
    "Lead Time Demand": 200,
    "Safety Stock": 50,
    "Reorder Point": 250,
    "Inventory Gap": 150,
    "Recommended Order Quantity": 150,
    "Risk": "High",
    "Recommended Action": "Replenish",
    "Priority": "High"
  }
]
```

The numeric values in this example are illustrative response-shape examples, not a claim about a specific real row.

### Errors

If the inventory artifact is missing, the route returns HTTP 503 with a detail message generated by the data service.

## Data service behavior

The API data service requires the following mounted paths:

- `/data/raw/sales_data.csv`
- `/data/processed/final_demand_forecasts.csv`
- `/data/processed/inventory_recommendations.csv`

The service uses Pandas to read the CSV artifacts. It does not recalculate Phase 5 forecasts or Phase 6 optimization inside the API.
